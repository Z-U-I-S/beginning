# 第一章 先认识网页的三件套

一个网页由三种语言分工合作，`2048.html` 把三者写在同一个文件里：

| 语言 | 角色 | 一句话理解 | 在本项目里负责 |
| --- | --- | --- | --- |
| HTML | 骨架 | 决定“页面上有什么” | 棋盘、按钮、侧边栏、说明文字 |
| CSS | 皮肤 + 排版 | 决定“长什么样、摆在哪” | 配色、渐变、圆角、动画、自适应 |
| JavaScript | 大脑 | 决定“做什么、怎么变” | 移动合并、计分、撤回、存档、AI |

关系是：**HTML 先搭好空架子，CSS 给它化妆，JavaScript 在运行时改变前两者的内容**。例如棋盘一开始只有 16 个空格子（HTML），JS 在游戏过程中不断往里面添加 `<div class="tile">` 方块（JavaScript 创建元素，CSS 立刻按新元素的规则给它上色）。

## 1.1 什么是最小可运行的网页

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>标题</title>
  <style> /* CSS 写在这里 */ </style>
</head>
<body>
  <h1>页面上显示的文字</h1>
  <script> /* JavaScript 写在这里 */ </script>
</body>
</html>
```

只要把这十几行存成 `.html` 文件，双击用浏览器打开，就是一个能跑的网页。我们的作品就是在它的 `<style>` 和 `<script>` 里不断加内容长大的。

## 1.2 “纯前端单文件”是什么意思

| 名词 | 含义 |
| --- | --- |
| 前端 | 所有代码都在浏览器里运行，不需要服务器计算 |
| 单文件 | HTML、CSS、JS 全写在同一个 `.html` 里，没有别的文件 |
| 无框架 | 不使用 Vue / React 等工具，只用浏览器原生支持的能力 |

好处是“双击就能玩、发给别人就能玩、不需要装任何东西”。

# 第二章 HTML：页面的骨架

## 2.1 标签、元素、属性

| 语法 | 写法 | 含义 |
| --- | --- | --- |
| 标签 | `<div>` | 一对尖括号，告诉浏览器“这里开始一个盒子” |
| 结束标签 | `</div>` | 表示这个盒子到此结束 |
| 元素 | `<div>内容</div>` | 开始标签 + 内容 + 结束标签，整体叫一个元素 |
| 属性 | `<div class="tile">` | 写在开始标签里的“设置项”，`class="tile"` 表示给它起个样式名 |
| 自闭合标签 | `<meta charset="UTF-8" />` | 没有内容的标签，自己就结束了 |

## 2.2 本项目用到的标签

| 标签 | 作用 | 在本项目中的例子 |
| --- | --- | --- |
| `<div>` | 通用盒子，最常用 | `<div class="board" id="board">` 棋盘 |
| `<span>` | 行内小段文字 | `<span>当前分数</span>` |
| `<h1>` ~ `<h3>` | 标题，数字越小字越大 | `<h1>2048</h1>` |
| `<p>` | 段落文字 | `<p>纯前端单文件 · 键盘 / 触屏 / AI 自动演示</p>` |
| `<ul>` / `<li>` | 无序列表 / 列表项 | 底部“游戏说明”的条目 |
| `<ol>` | 有序列表 | 侧边栏历史记录 `<ol class="history">` |
| `<button>` | 按钮，可以点击 | `<button class="btn" id="btnUndo">撤回</button>` |
| `<select>` / `<option>` | 下拉框 / 选项 | AI 速度选择（慢 / 中 / 快） |
| `<label>` | 表单控件的文字说明 | `<label class="select-wrap">速度</label>` |
| `<header>` | 页头区域（语义化） | 顶部分数栏 |
| `<main>` | 页面主体 | 棋盘 + 侧边栏 |
| `<section>` | 一个内容区块 | `<section class="stage">` |
| `<aside>` | 侧边内容 | 右侧历史侧边栏 |
| `<article>` | 独立的一篇文章 | 底部“游戏说明 / 游戏玩法” |
| `<footer>` | 页脚 | 本项目写在说明区之后 |
| `<style>` | 存放 CSS | `<head>` 里 |
| `<script>` | 存放 JS | `</body>` 前 |
| `<meta>` | 页面元信息 | `<meta charset="UTF-8" />` 声明编码，防止中文乱码 |

> **语义化标签**（header / main / aside / article）和 `<div>` 在显示上没有区别，但能让代码更好读、对无障碍和搜索引擎更友好。所以本项目“大区块用语义标签，小零件用 div”。

## 2.3 两个重要属性：class 和 id

| 属性 | 写法 | 含义 | 特点 |
| --- | --- | --- | --- |
| `class` | `class="tile tile--new"` | 样式类名 | 一个元素可以有**多个**，用空格分隔；多个元素可以共用同一个类名 |
| `id` | `id="board"` | 唯一编号 | 同一个页面里**只能有一个**同 id 元素，JS 用它精确找到元素 |

在项目里的配合方式：

```html
<div class="board" id="board">   <!-- class 给 CSS 用，id 给 JS 用 -->
```

## 2.4 data-* 自定义属性

HTML 允许我们自定义 `data-` 开头的属性来存一点数据：

```html
<div class="tile" data-value="2048" data-len="4"></div>
```

在 JS 里通过 `dataset` 读写：

```js
node.dataset.len = String(String(value).length);   // 写入 data-len="4"
```

CSS 也能用它来做条件样式：

```css
.tile[data-len="4"] { font-size: clamp(13px, 5vw, 22px); }   /* 四位数用更小的字号 */
```

这是“样式跟着数据走”的典型技巧：数字位数一变，字号自动切换，不用写一行 JS 判断。

## 2.5 hidden 属性

```html
<div class="board-overlay" id="boardOverlay" hidden> ... </div>
```

`hidden` 是 HTML 自带的“隐藏”开关，效果等于 CSS 的 `display: none`。JS 里可以这样控制：

```js
el.boardOverlay.hidden = false;   // 显示浮层
el.boardOverlay.hidden = true;    // 隐藏浮层
```

本项目用它控制“本局结束 / 达成 2048”的浮层，以及侧边栏“还没有记录”的提示。

# 第三章 CSS：样式、布局与动画

## 3.1 选择器：怎么“选中”元素

| 选择器 | 写法 | 含义 | 项目中的例子 |
| --- | --- | --- | --- |
| 元素选择器 | `body { }` | 选中所有该标签 | `body { margin: 0; }` |
| 类选择器 | `.tile { }` | 选中 class 为此名的元素 | `.tile { position: absolute; }` |
| id 选择器 | `#board { }` | 选中该 id 的元素 | 用得少，因为 id 主要给 JS |
| 后代选择器 | `.history li { }` | 选中 `.history` 里面的所有 `li` | 历史列表条目样式 |
| 分组选择器 | `h1, h2, h3 { }` | 同时给多个选择器写样式 | `h1, h2, h3 { margin: 0; }` |
| 属性选择器 | `.tile[data-len="4"]` | 选中带指定属性的元素 | 字号分级 |
| 伪类 | `.btn:hover { }` | 鼠标悬停时生效 | 按钮浮起效果 |
| 伪类 | `.btn:disabled { }` | 按钮被禁用时生效 | 撤回栈为空时按钮变灰 |

常用伪类一览：`:hover`（悬停）、`:active`（按下）、`:disabled`（禁用）、`:first-child`（第一个子元素）。

## 3.2 盒模型与 box-sizing

每个元素都是一个矩形盒子，由里到外是：**内容 → 内边距 padding → 边框 border → 外边距 margin**。

默认情况下 `width` 只算内容宽度，一旦加了 padding 和 border，盒子就会被撑大，计算很烦。所以本项目在最开头统一改成“宽度包含内边距和边框”：

```css
* { box-sizing: border-box; }   /* * 表示所有元素 */
```

这样写布局时就可以放心地说“这个盒子就是 460px 宽”。

## 3.3 长度单位与计算函数

| 单位 / 函数 | 含义 | 例子 |
| --- | --- | --- |
| `px` | 像素，绝对长度 | `padding: 12px;` |
| `%` | 相对父元素尺寸 | `width: 25%;` |
| `vw` | 视口宽度的 1% | `clamp(18px, 7.4vw, 32px)` |
| `rem` / `em` | 相对字号 | `font-size: 1.2rem` |
| `calc()` | 允许把不同单位放在一起算 | `width: calc(25% - var(--gap) * 0.75);` |
| `clamp(最小, 理想, 最大)` | 取中间值，且被限制在区间内 | `font-size: clamp(13px, 5vw, 22px);` |

`calc()` 是本项目布局的关键：棋盘用百分比自适应宽度，方块间距用像素固定，两者必须用 `calc()` 混算才不会错位。

## 3.4 颜色写法

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `#RRGGBB` | 十六进制颜色，两位一组表示红绿蓝 | `#E8452F`（红色） |
| `#RGB` | 简写 | `#fff` = `#FFFFFF` |
| `rgba(r, g, b, a)` | 带透明度（a 从 0 到 1） | `rgba(232, 69, 47, .12)` |

本项目里每一种颜色都取自任务书的配色要求：2 到 64 由白渐变到红，128 到 2048 由浅黄渐变到深黄，4096 以上为黑。

## 3.5 颜色渐变：linear-gradient

```css
background: linear-gradient(135deg, #F0634C, #E8452F);
```

含义：从 135° 方向（左上到右下）开始，颜色由 `#F0634C` **平滑过渡**到 `#E8452F`。JS 里则用模板字符串拼接每个方块自己的两个颜色：

```js
node.style.background = `linear-gradient(135deg, ${style.from}, ${style.to})`;
```

## 3.6 Flex 弹性布局

```css
.layout { display: flex; gap: 20px; align-items: flex-start; }
.sidebar { flex: 0 0 320px; }
.stage { flex: 1 1 460px; min-width: 0; }
```

| 属性 | 含义 |
| --- | --- |
| `display: flex` | 让子元素排成一行（或一列），是最好用的布局方式 |
| `gap` | 子元素之间的间距 |
| `align-items` | 交叉轴（这里指纵向）对齐方式，`flex-start` 表示顶部对齐 |
| `justify-content` | 主轴对齐，`space-between` 表示两端撑开 |
| `flex-wrap: wrap` | 一行放不下就换行，小屏幕必需 |
| `flex: 1 1 460px` | 可放大、可缩小、理想基准宽度 460px |
| `flex: 0 0 320px` | 放大 0、缩小 0，宽度固定 320px |

顶部状态栏、工具栏、底部说明区、侧边栏全部靠 Flex 排版。

## 3.7 Grid 网格布局

棋盘背面的 16 个浅色格子用 Grid 一行代码搞定：

```css
.grid-bg {
  display: grid;
  grid-template-columns: repeat(4, 1fr);   /* 4 列，每列等分 */
  grid-template-rows: repeat(4, 1fr);      /* 4 行，每行等分 */
  gap: var(--gap);
}
```

| 属性 | 含义 |
| --- | --- |
| `display: grid` | 开启网格布局 |
| `grid-template-columns: repeat(4, 1fr)` | 分成 4 列，`1fr` 表示“平分剩下空间” |
| `gap` | 网格间距，横竖同时生效 |

## 3.8 定位：relative / absolute

```css
.board { position: relative; }                    /* 棋盘：定位参照物 */
.grid-bg { position: absolute; inset: var(--pad); } /* 网格：贴住棋盘内边距 */
.tile { position: absolute; left: 0; top: 0; }    /* 方块：绝对定位，随 left/top 移动 */
```

| 写法 | 含义 |
| --- | --- |
| `position: relative` | 自己还在原位，但成为子元素定位的“参照物” |
| `position: absolute` | 脱离正常排布，相对最近的已定位祖先元素摆放 |
| `inset: 12px` | `top/right/bottom/left` 四个方向的简写 |
| `left` / `top` | 距离参照物左边 / 上边的距离 |

因为 `.tile` 是绝对定位，所以给它的 `left` / `top` 赋新值就等于“把它搬到另一个地方”，再配合 `transition` 就变成了平移动画。

## 3.9 z-index 与层叠顺序

```css
.tile { z-index: 10; }              /* 数值越大越靠上（只在方块层内部比较） */
.tile-layer { z-index: 1; }         /* 方块层自己成为一层 */
.board-overlay { z-index: 5; }      /* 浮层只要比方块层大就能盖住全部方块 */
```

`z-index` 决定“谁盖住谁”，只在定位元素上生效。项目中 JS 每创建一个新方块就自增一次 `zIndex`，保证后出现的方块显示在最上层：

```js
node.style.zIndex = String(++zIndex);
```

**这里有个必须知道的概念：层叠上下文（stacking context）。** 如果一个元素自己设置了定位和 `z-index`，它就“另起一层”，它所有子元素的 `z-index` 只在**这一层内部**比大小，永远不可能越级盖住外面的元素。

在本项目里，`.tile-layer` 的 `z-index: 1` 就是干这个的：方块在里面即使涨到 783，也小于浮层的 5，所以“本局结束 / 达成 2048”的提示框永远不会被数字块盖住。

> 常见困惑：**为什么把子元素的 `z-index` 调到 99999，还是盖不住某个元素？** 多半就是因为它们不在同一个层叠上下文里——子元素的 99999 只在自己那一层有效。

## 3.10 CSS 变量（自定义属性）

```css
:root {
  --gap: 12px;
  --slide: 120ms;
  --bg: #f4f1ec;
  --text: #35322e;
}
html[data-theme="dark"] {
  --bg: #191a1d;
  --text: #f1eeea;
}
```

| 写法 | 含义 |
| --- | --- |
| `:root` | 选中 `<html>` 根元素 |
| `--名字: 值` | 定义一个 CSS 变量（必须以两个减号开头） |
| `var(--名字)` | 使用这个变量 |
| `html[data-theme="dark"]` | 当 `<html data-theme="dark">` 时生效 |

**这就是“主题切换”的全部秘密**：所有颜色都不写死，而是写成变量。JS 只改一个属性：

```js
document.documentElement.dataset.theme = 'dark';
```

所有 `var(--bg)`、`var(--text)` 会立刻换成深色主题的值，页面瞬间换肤——不用遍历修改任何一个元素。

## 3.11 transition：过渡动画

```css
.tile { transition: left var(--slide) ease-in-out, top var(--slide) ease-in-out; }
.btn { transition: transform .12s ease, background .2s ease; }
```

含义：当 `left` / `top` 的值发生变化时，**不要瞬间跳过去，而是用 120ms 平滑过渡**。语法拆解：

```text
transition: 要过渡的属性 时长 速度曲线, 第二个属性 时长 速度曲线;
```

四种状态变化最适合用 transition：鼠标悬停、按下、类名切换、坐标改变。我们的“方块滑动”完全靠它实现，JS 一行动画代码都不用写。

## 3.12 @keyframes + animation：关键帧动画

```css
@keyframes tile-merge {
  0%   { opacity: 0; transform: scale(.3); }
  60%  { opacity: 1; transform: scale(1.16); }
  100% { opacity: 1; transform: scale(1); }
}
.tile--merged { animation: tile-merge 200ms ease-out var(--slide) both; }
```

| 部分 | 含义 |
| --- | --- |
| `@keyframes 名字` | 定义动画的“剧本”，用百分比描述每个时间点的样子 |
| `opacity` | 透明度，0 全透明、1 不透明 |
| `transform: scale(1.16)` | 放大到 1.16 倍（`transform` 不影响其他元素布局，最适合做动效） |
| `animation: 名称 时长 曲线 延迟 填充模式` | 把剧本套到元素上 |
| `var(--slide)` 位置 | 这是**延迟**：先等 120ms 让旧方块滑完，再播自己 |
| `both`（fill-mode） | 动画开始前先应用 0% 的样子（所以延迟期间是隐藏的），结束后保持 100% 的样子 |

**为什么需要这个延迟？** 合并时如果新方块立刻出现，会看到“方块还没滑到位就蹦出了新数字”。加上延迟后，观感变成“两块撞在一起 → 弹出新数字”，这就是本项目最关键的一处动效设计。

## 3.13 媒体查询：适配手机

```css
@media (max-width: 900px) {
  .layout { flex-direction: column; }   /* 竖排：侧边栏挪到棋盘下面 */
  .sidebar { width: 100%; }
}
```

含义：当屏幕宽度 ≤ 900px 时，应用大括号里的样式。这样电脑上是“左棋盘 + 右侧栏”，手机上是“上棋盘 + 下侧栏”。

| 属性 | 作用 | 项目中的位置 |
| --- | --- | --- |
| `border-radius` | 圆角 | 卡片、方块、按钮 |
| `box-shadow` | 阴影，做出立体感 | 面板、棋盘 |
| `font-weight: 800` | 字体粗细 | 方块数字 |
| `line-height` | 行高，控制行间距 | 说明文字 |

| `cursor: pointer` | 鼠标变成小手 | 按钮 |
| `animation: blink 1.1s infinite` | 无限循环动画 | AI 状态小圆点闪烁 |

# 第四章 JavaScript：让页面动起来

## 4.1 变量：const 与 let

```js
const SIZE = 4;          // 常量：定义后不能重新赋值
let score = 0;           // 变量：后面会被修改
```

| 关键字 | 能否重新赋值 | 建议 |
| --- | --- | --- |
| `const` | 不能 | **默认都用它**，能防止误改 |
| `let` | 能 | 确实需要变化时才用（分数、步数、状态） |
| `var` | 能 | 老写法，有作用域坑，本项目不用 |

> 小提示：`const` 只是“这个变量名不能再指向别的值”，但指向的对象内部仍可修改，比如 `const el = {}` 之后依然可以 `el.board = ...`。

## 4.2 数据类型

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| number 数字 | `4`、`0.9`、`2048` | 不区分整数和小数 |
| string 字符串 | `'left'`、`` `得分 ${score}` `` | 单引号、双引号、反引号都可以 |
| boolean 布尔 | `true` / `false` | 真 / 假 |
| null | `null` | 明确表示“这里是空的” |
| undefined | `undefined` | 还没赋值 |
| object 对象 | `{ id: 1, value: 2 }` | 一堆键值对 |
| array 数组 | `[2, 4, 8]` | 有序的一串值 |

## 5.1 一段 CSS：方块为什么能滑动

```css
.tile {
  position: absolute;                                                    /* ① */
  left: 0; top: 0;                                                       /* ② */
  width: calc(25% - var(--gap) * 0.75);                                  /* ③ */
```

| 行 | 含义 |
| --- | --- |
| ① | 让方块脱离普通排版，可以自由摆放，并相对棋盘定位 |
| ② | 初始位置在左上角，真正的坐标稍后由 JS 用 `style.left/top` 覆盖 |
| ③ | 一格宽度 = 棋盘宽度的 25% 减去 3/4 个缝隙；高度同理，得到正方形 |
| ④ | left/top 变化时用 120ms 平滑过渡——**方块会滑动，全靠这一行** |

配套的 JS 只有两行：

```js

tile.el.style.left = `calc(${tile.col} * ${step})`;   // 第 col 格的左偏移
```

`tile.col` 从 0 变到 3，`left` 的值就变，浏览器自动补上中间的过渡帧——这就是“让数据驱动动画”的思路：**JS 只改数据，动画交给 CSS**。

## 5.2 一段算法：合并是怎么算出来的

```js
const blocks = [];
for (let i = 0; i < cells.length; i++) {
  if (cells[i] > 0) blocks.push({ value: cells[i], index: i });   // ① 挤掉空格
}

let k = 0;
let outIndex = 0;
while (k < blocks.length) {
  const cur = blocks[k];
  const next = blocks[k + 1];
  if (next && next.value === cur.value) {                          // ② 相邻相同 → 合并
    merges.push({ from: [cur.index, next.index], to: outIndex, value: cur.value * 2 });
    result.push(cur.value * 2);
    gained += cur.value * 2;
    k += 2;                                                        // ③ 跳过两块，不会连锁合并
  } else {                                                         // ④ 不同 → 单独滑过去
    slides.push({ from: cur.index, to: outIndex });
    result.push(cur.value);
    k += 1;
  }
  outIndex++;
}
```

| 步骤 | 大白话 |
| --- | --- |
| ① | 把一行里的方块“压实”，`[2,0,2,4]` 变成 `[2,2,4]`，同时记住每个数字原来的位置 |
| ② | 从压实的第一个开始，看它和右边那个数是不是一样 |
| ③ | 一样就合成两倍、跳过这两块——这就是“同一块一步只合并一次”的全部实现 |
| ④ | 不一样就让它自己继续往前，只移动，不合并 |

以 `[2,2,2,2]` 为例，循环过程是：k=0 时 2 和 2 相同 → 合成 4，k 跳到 2；k=2 时又是 2 和 2 相同 → 合成 4，k 跳到 4 结束。结果 `[4,4,0,0]`，绝不会变成 `[8,0,0,0]`。

## 5.3 一段事件代码：一次点击发生了什么

```js
function undo() {
  if (undoStack.length === 0) return;          // ① 没得撤就直接返回
  if (roundEnded) { /* ② 死局撤回：撤销刚写入的战绩记录并复活本局 */ }
  const snap = undoStack.pop();                // ③ 弹出最近一个快照
  score = snap.score;                          // ④ 还原分数
  moves = snap.moves;                          // ⑤ 还原步数
  rebuildBoard(snap.values);                   // ⑥ 按快照重建棋盘 DOM
  won = coreMaxTile(snap.values) >= 2048;      // ⑦ 重新判断“是否已达成 2048”
  renderStats();                               // ⑧ 刷新顶部数字与按钮状态
}
```

| 步骤 | 讲解 |
| --- | --- |
| ① | 卫语句：栈是空的（还没走过）就什么都不做 |
| ② | 本局已结束时，先把侧边栏里刚写入的那条记录删掉，避免“复活后同局两条记录” |
| ③ | `pop()` 既“取出最后一个”又“把它从数组里删掉”，天然实现“撤回一步” |
| ④⑤ | 分数与步数必须和棋盘一起回退，否则数字对不上 |
| ⑥ | 清空所有方块 DOM，按旧棋盘重新创建——最快也最不容易出错的还原方式 |
| ⑦ | 撤回之后可能从“已达成 2048”退回未达成，状态要跟着重算 |
| ⑧ | 数据变了，界面必须重新渲染一遍（这是所有 UI 框架的核心思想：**数据 → 视图**） |

# 第六章 调试与排错

## 6.1 出错了怎么办

1. 在浏览器里按 `F12`（或右键 → 检查）打开开发者工具。
2. 切到 **Console（控制台）** 面板，红色文字就是报错，点右边的文件名可以跳到出错那行。
3. 在代码里加 `console.log(要看的变量)`，刷新页面即可在控制台看到它的值。这是最朴素也最有效的调试手段。
4. 在 **Elements（元素）** 面板里可以看到实时的 HTML 和 CSS，鼠标悬停能高亮页面上的对应元素，用来排查“样式没生效”特别快。

## 6.2 新手最常见的问题

| 现象 | 常见原因 | 解决办法 |
| --- | --- | --- |
| 页面一片空白 | JS 报错中断了后续执行 | 打开控制台看第一条红色错误 |
| 中文变成乱码 | 缺少字符编码声明 | 加上 `<meta charset="UTF-8" />` |
| 样式完全不生效 | 选择器写错 / 类名拼错 / `<style>` 没写对位置 | 用 Elements 面板检查类名是否真的存在 |
| 数字一直是 0 | 变量没更新，或忘了调用渲染函数 | 在 `renderStats()` 里 `console.log` 确认被调用 |
| 元素明明创建了却看不到 | 忘了 `appendChild`，或被 `z-index` 盖住 | 检查是否挂到页面上、层级是否够高 |
| 点击没反应 | 事件名写错（是 `'click'` 不是 `'onclick'`）或函数没定义 | 控制台会提示 `xxx is not defined` |
| 动画一闪而过 | 元素被立刻删除 | 用 `setTimeout` 延迟删除（本项目用 `SLIDE_MS`） |
| 手机滑动时整页跟着滚 | 没有禁用默认手势 | 加 `touch-action: none` |
| 刷新后数据没了 | 没有写进 localStorage | 检查 `writeStore` 是否被调用 |

## 6.3 一个真实例子：颜色对比度

任务书要求“数字统一为白色”，同时要求“数字 2 的底色为白色”。这两条同时执行会让白色的 2 完全看不见。解决办法是**在冲突的需求之间做工程判断**：方块 2 用深灰数字保证可读，其余方块保持白字，并给浅色底上的白字加 `text-shadow` 阴影提高对比度。这说明一条重要的经验：**需求冲突时，要说明取舍的理由，而不是硬写下去**。
